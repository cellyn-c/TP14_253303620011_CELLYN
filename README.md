# MyTaskList App

**Nama:** Isi Nama Kamu  
**NIM:** Isi NIM Kamu

MyTaskList adalah aplikasi pengelola tugas sederhana untuk membantu mahasiswa mencatat tugas, menentukan prioritas, dan memantau pekerjaan yang sudah selesai.

## Fitur
- [x] Tambah tugas baru
- [x] Validasi agar judul tugas tidak boleh kosong
- [x] Hapus tugas
- [x] Mark as Done
- [x] Prioritas Rendah, Sedang, Tinggi
- [x] Counter tugas selesai dari total tugas
- [x] Filter Semua, Aktif, Selesai
- [x] FlatList dan empty state
- [x] KeyboardAvoidingView

## Cara menjalankan

1. Install Node.js dan VS Code.
2. Extract folder project.
3. Buka terminal pada folder project.
4. Jalankan:

```bash
npm install
npx expo start
```

5. Pastikan HP dan komputer terhubung ke jaringan yang sama.
6. Buka Expo Go di HP, lalu scan QR Code dari terminal/browser.

## Teknologi
- React Native
- Expo
- JavaScript
- useState
- FlatList
- StyleSheet dan Flexbox
